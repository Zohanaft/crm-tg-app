# Промпт для Capacity.io — дизайн по текущей платформе

Скопируй текст ниже в Capacity.io для генерации дизайна.

---

## Текст промпта

Создай визуальный и UI/UX дизайн веб-платформы (CRM для Telegram-ботов) по следующему описанию. **Обязательно используй стили, совместимые с Nuxt UI и Tailwind CSS**: классы и паттерны, которые легко перенести в разметку с `UButton`, `UCard`, `UInput`, `UForm`, `UAvatar` и утилитами Tailwind (spacing, typography, colors, borders, dark mode).

### О платформе
- **Тип:** веб-приложение (CRM для управления Telegram-ботами).
- **Стек фронтенда:** Nuxt 3, Vue 3, **@nuxt/ui**, **Tailwind CSS**. Дизайн должен быть реализуем компонентами Nuxt UI и утилитами Tailwind без кастомных фреймворков.
- **Языки:** интерфейс на двух языках (EN/RU), нужны нейтральные или легко адаптируемые подписи в макетах.
- **Тема:** поддержка светлой и тёмной темы (как в Nuxt UI: `dark:` варианты, семантические цвета `primary`, `gray`, `muted`).

### Структура экранов
1. **Общая оболочка**
   - Верхняя шапка (header): логотип слева; навигация (например «Как начать», «Что нового»); справа — переключатель языка, переключатель темы, для авторизованного пользователя — «Профиль» и «Выйти», для гостя — «Войти» и «Регистрация».
   - Контентная область: центрированный контейнер (`container`, `mx-auto`), комфортные отступы (`p-6`/`p-8`).

2. **Главная (лендинг)**
   - Крупный заголовок приветствия и короткое описание продукта (CRM Telegram App).

3. **Информационные страницы**
   - «Как начать» и «Что нового»: заголовок, подзаголовок/описание, блок контента (текст, при необходимости списки или карточки). Стиль — читаемая типографика, `prose`-подобная подача.

4. **Дашборд (после входа)**
   - Приветствие с именем пользователя.
   - Кнопка действия «Подключить бота» (основное или outline).
   - Секция «Ваши боты»: список карточек ботов. Каждая карточка — заголовок (имя/username бота, ID), тело с полями (токен/ID, даты и т.д.), при необходимости раскрывающийся блок «Raw data». Состояния: загрузка, пустой список, ошибка — предусмотреть текстовые и визуальные состояния.

5. **Подключение бота**
   - Одна форма в карточке: поле ввода токена (тип password), кнопка «Подключить». Сообщения об успехе/ошибке (toast или inline).

6. **Профиль пользователя**
   - Карточка с аватаром (круглый), имя, username, Telegram ID. Аккуратная типографика и отступы.

7. **Авторизация**
   - Страницы «Вход» и «Регистрация»: форма (email, пароль, плейсхолдеры), кнопка отправки, при необходимости «Продолжить с Telegram» и текст о недоступности сервиса.

### Требования к стилю (Nuxt UI + Tailwind friendly)
- **Цвета:** использовать палитру, совместимую с Nuxt UI (primary, gray, success, error и т.д.). В макетах указывать классы или токены вроде `text-muted-foreground`, `bg-white dark:bg-gray-900`, `border-gray-200 dark:border-gray-800`.
- **Типографика:** заголовки — `text-3xl font-bold`, подзаголовки — `text-xl font-semibold`, мелкий текст — `text-sm text-muted-foreground`. Шрифты — те, что обычно идут с Nuxt UI / Tailwind (например sans-serif).
- **Отступы и сетка:** `space-y-4`, `gap-4`, `p-4`/`p-6`/`p-8`, `mb-4`/`mb-6`. Контейнеры — `max-w-md` для форм, `max-w-2xl` для профиля, без жёсткого max-width для дашборда.
- **Компоненты:** карточки с заголовком и телом (как `UCard` с header/default slots), кнопки — варианты primary / outline / ghost, поля ввода — с label и placeholder. Иконки — стиль Lucide/Outline, если нужны (например chevron-down, user).
- **Списки и таблицы:** если есть списки — использовать те же отступы и разделители, что легко сверстать через Tailwind (например `divide-y`, `space-y-4`).
- **Адаптивность:** мобильный и десктоп; на мобильном — компактная шапка, стекирование блоков, кнопки на всю ширину где уместно (`block`).

Сгенерируй дизайн (макеты/прототипы) для перечисленных экранов с учётом этих правил, чтобы разработчик мог переносить их в код на Nuxt UI + Tailwind без перепридумывания стилей.
